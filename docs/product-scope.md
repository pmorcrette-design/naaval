# Product Scope

## Core company management

To run a full last-mile delivery business, the platform should manage more than route optimization.
The minimum company-grade modules are:

- Companies and subsidiaries
- Merchant accounts and contracts
- Hubs, depots, and service zones
- Vehicle types, capacities, and costs
- Drivers, shifts, breaks, and eligibility rules
- Carrier partners and subcontracting logic
- Delivery orders, pickups, returns, and exchanges
- Service levels and time windows
- Planning, dispatch, execution, and incident handling
- Pricing, surcharges, settlements, and billing exports
- Support tooling and audit trails

## Order model

Each delivery order should support:

- External reference and merchant reference
- Pickup and drop-off addresses
- Geocoded coordinates
- Promised slot or hard time windows
- Parcel count and capacity dimensions
- Skills or handling constraints
- Cash collection or age check requirements if needed
- Notes, contact instructions, and access rules

## Fleet model

Fleet and workforce planning should support:

- Dedicated fleet and subcontracted carriers
- Vehicle profiles such as bike, scooter, van, refrigerated van
- Capacity dimensions like weight, volume, parcel count
- Skills such as chilled, fragile, heavy, or licensed
- Driver calendars, shifts, breaks, and availability
- Start and end depots

## Control tower features

- Planning board by date, hub, and route wave
- Map view with route overlays and live markers
- SLA risk alerts
- Reassignment and route override tools
- Driver support console
- Incident and customer complaint handling
- End-of-day operational summary

## Carrier app features

- Secure login
- Shift start and vehicle checklist
- Route acceptance
- Stop list ordered by route sequence
- One-tap status changes: arrived, picked up, delivered, failed
- Barcode or parcel scan support
- Signature, photo, and OTP proof flows
- Failure reasons and incident reporting
- Cash handling if the business needs COD
- Offline mode and background sync

## Data and analytics

- OTIF and SLA metrics
- On-road productivity
- Failed delivery reasons
- Route cost and density metrics
- Driver performance snapshots
- Merchant-facing reporting exports
