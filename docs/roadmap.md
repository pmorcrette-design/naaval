# Delivery Roadmap

## Phase 1 - Core MVP

- Merchant and order intake
- Fleet and shift setup
- GraphHopper-powered planning
- Manual dispatch
- Carrier route execution
- Proof of delivery
- Live operations dashboard

## Phase 2 - Operational depth

- Multi-hub planning
- Dynamic re-optimization
- Customer notifications
- Exception workflows
- Returns and exchanges
- Basic billing exports

## Phase 3 - Scale features

- Carrier partner portal
- White-label merchant reporting
- Driver performance and incentive logic
- Capacity forecasting
- SLA prediction

## Phase 4 - Advanced optimization

- Multi-day planning
- Multi-trip vehicles
- Cost-aware optimization by partner
- Custom cost matrices
- Slot pricing and delivery promise engine
