Naaval Carrier App

Installation iPhone de l’application chauffeur.

Naaval Carrier App est une véritable application mobile d’entreprise. Ce n’est pas un raccourci web. L’installation iPhone suit une logique d’application privée / entreprise Apple.

1. Recevoir le lien d’installation

L’utilisateur reçoit un lien d’installation fourni par Naaval ou par l’équipe ops de son entreprise, avec la build iPhone d’entreprise.

2. Lancer l’installation

iOS télécharge l’application métier. Selon la configuration du terminal, un message peut indiquer que le développeur d’entreprise n’est pas encore approuvé.

3. Valider le développeur

Sur iPhone, ouvrir Réglages > Général > VPN et gestion de l’appareil, sélectionner le profil développeur de l’entreprise puis cliquer sur Faire confiance ou Autoriser et redémarrer selon la version d’iOS.

4. Ouvrir Naaval Carrier App

Une fois le profil approuvé, l’application peut être ouverte normalement et reliée au compte chauffeur attribué depuis Naaval Ops.
